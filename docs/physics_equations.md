# Физические уравнения

Все уравнения записаны в осесимметричной формулировке (зависимость только от `r`, `z`; `∂/∂θ = 0`).

> Документ описывает **и постановку, и то, что реально считает код**. Там, где
> они расходятся, расхождение названо явно — молчаливых упрощений здесь быть
> не должно, именно на такое молчание указал Reviewer #1.

## Уравнения равновесия

В цилиндрической системе координат остаются два нетривиальных уравнения
(полная осесимметричная форма):

```
∂σ_rr/∂r + ∂τ_rz/∂z + (σ_rr − σ_θθ) / r = 0        (1)
∂τ_rz/∂r + ∂σ_zz/∂z + τ_rz / r = 0                 (2)
```

**Что из этого реально считает код.** Вход сети — `X = [Q, k, α, μ, v, r]`,
координаты `z` в нём нет, поэтому осевые производные не вычисляются вообще.
В `L_pde` входят редуцированные выражения:

```
R₁(r) = ∂σ_rr/∂r + (σ_rr − σ_θθ) / r
R₂(r) = ∂τ_rz/∂r + τ_rz / r
```

Производные — через автоматическое дифференцирование (PyTorch autograd /
DeepXDE / JAX), в нормированных координатах, пересчёт в физические по цепному
правилу. Веса физических потерь подбираются в Optuna.

**Насколько это законно.** Отброшенные члены оценены численно по сырым полям
Abaqus (2443 набора, `publication/audit/RAW_AUDIT.md`, §6). Медианы отношения
отброшенного члена к сумме удержанных:

| уравнение | отброшено | отношение (медиана) | сдвиг невязки |
|---|---|---|---|
| (1) радиальное | `∂τ_rz/∂z` | **0.013** | 6 % |
| (2) осевое | `∂σ_zz/∂z` | **0.68** | 32 % |

Отсюда два разных вывода, и их нельзя объединять:

* для **(1)** редукция оправдана — в осевом окне 25–75 % поля по `z` почти
  однородны, и `∂τ_rz/∂z` на два порядка меньше удержанных членов;
* для **(2)** редукция **не** оправдана: отброшенный член того же порядка, что
  удержанные. Выражение `∂τ_rz/∂r + τ_rz/r` осевым равновесием **не является**
  и так называться не должно. Оно остаётся в лоссе как регуляризатор гладкости
  сдвига — либо, если нужна настоящая (2), во вход сети надо вводить `z`
  (заготовка: флаг `use_z` в `models/strain/pinn_total_strain_system.py`).

Апостериорная метрика физической согласованности считает те же редуцированные
выражения (`numpy.gradient` по `r`), чтобы метрика и лосс совпадали:

```python
R_1(r) = d(sigma_rr)/dr + (sigma_rr - sigma_tt) / r_safe
R_2(r) = d(tau_rz)/dr  + tau_rz / r_safe          # НЕ осевое равновесие, см. выше
```

Производные считаются через `numpy.gradient`. Деление на `r` стабилизируется через `r_safe = max(r, 0.05)`. Граничные точки (`r = 0`, `r = 1`) исключаются из усреднения, потому что:

- одностороннее конечно-разностное приближение там менее точно,
- член `1/r` имеет особенность на оси.

## Граничное условие на поверхности проволоки

Двадцать радиальных точек профиля покрывают **весь** радиус: `r_norm = 0` —
ось симметрии, `r_norm = 1` — свободная поверхность. Окно «25–75 %» относится
к **осевой** координате `z` (зона выхода процесса на стационар), а не к радиусу;
проверено по сырым `.rpt`: медиана `r_max(окно)/R = 0.996`
(`publication/audit/RAW_AUDIT.md`, §2).

На свободной границе поверхностные усилия равны нулю:

```
σ_rr |_{r_norm=1} = 0
τ_rz |_{r_norm=1} = 0
```

Это условие используется как `L_bc` и там же проверяется в аудите.

> ⚠ **Расхождение с текущим кодом моделей.** В `models/pinn_model_*.py` и
> `models/vpinn_model.py` стоит `R_EXTRAP_FREE_SURFACE = 1.5` — ГУ налагается
> при `r_norm = 1.5`, то есть на радиусе `1.5 R`, вне материала. Основание для
> этого («данные покрывают 25–75 % радиуса, поверхность при 1.5») данными не
> подтверждается. Корректное значение — `1.0`; см. `publication/code/physics_check.py`
> и запись E-01 в `publication/ERRATA.md`. До перезапуска обучения с
> `r_surface = 1.0` числа нарушения ГУ из отклонённой версии рукописи цитировать
> нельзя: там условие налагалось в одной точке, а измерялось в другой.

**Базовая линия.** Сами данные FEM удовлетворяют условию лишь приближённо:
средний `|σ_rr|` в крайней точке профиля = 3.8 МПа, `|τ_rz|` = 0.5 МПа по всем
2443 сырым наборам. Метрику нарушения ГУ у моделей осмысленно печатать только
рядом с этой строкой — иначе не видно, что именно измеряется.

## Уравнения совместности Сен-Венана (для деформаций)

В осесимметричном случае из шести общих уравнений совместности остаются два:

```
∂²ε_rr/∂z² + ∂²ε_zz/∂r² − (1/r) ∂ε_zz/∂r
    = (1/r) ∂/∂r ( r · ∂ε_rz/∂z )

∂²ε_θθ/∂z² + (1/r) ∂/∂r ( r · ∂ε_θθ/∂z )
    = 0
```

**Важно:** эти уравнения справедливы только для **полных** деформаций (упругие + пластические), а не для пластических по отдельности. В текущем датасете доступны только пластические компоненты в одной z-плоскости, поэтому уравнения совместности используются как мягкий регуляризатор с весом `λ_compat = 1e-4`. Полная активация — после получения 2D total strain экспорта из Abaqus, тогда `λ_compat` нужно повысить до 0.1–1.0 и переподобрать через Optuna.

## Кинематические соотношения

```
ε_r     = ∂u/∂r
ε_θ     = u / r
ε_z     = ∂w/∂z
γ_rz    = ∂u/∂z + ∂w/∂r
```

где `u(r, z)` — радиальное перемещение, `w(r, z)` — осевое.

## Закон Гука с температурой (термоупругость)

Для неизотермической задачи упругие деформации связаны с напряжениями через:

```
ε_r^e = (1/E) [σ_r − ν (σ_θ + σ_z)] + α T
ε_θ^e = (1/E) [σ_θ − ν (σ_r + σ_z)] + α T
ε_z^e = (1/E) [σ_z − ν (σ_r + σ_θ)] + α T
γ_rz  = τ_rz / G,   G = E / (2 (1 + ν))
```

где `E` — модуль Юнга, `ν` — коэффициент Пуассона, `α` — коэффициент теплового расширения, `T` — температура относительно отсчёта.

Поскольку в датасете записаны только **пластические** компоненты, для вычисления полных деформаций (`ε = ε^e + ε^p`) нужно сначала найти упругие через эту формулу из тензора напряжений и поля температур.

## Эффективное напряжение фон Мизеса

```
σ_eff = sqrt( σ_rr² + σ_θθ² + σ_zz²
              − σ_rr·σ_θθ − σ_rr·σ_zz − σ_θθ·σ_zz
              + 3 τ_rz² )
```

Используется как агрегированная скалярная метрика напряжённого состояния в скаттер-плотах и таблицах.

## Критерий пластичности и модель Джонсона–Кука

Условие пластического течения:

```
σ_eff ≤ σ_y
```

где предел текучести описывается термо-вязко-пластической моделью Джонсона–Кука:

```
σ_y = (A + B ε_p^n) (1 + C ln(ε̇_p / ε̇_0)) (1 − T*^m)
T*  = (T − T_0) / (T_m − T_0)
```

Параметры стали (пример из ВКР): `A = 500 МПа`, `B = 300 МПа`, `n = 0.4`, `C = 0.05`, `m = 1.0`, `ε̇_0 = 1 с⁻¹`, `T_0 = 300 K`, `T_m = 1800 K`.
