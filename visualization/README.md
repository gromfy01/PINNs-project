# visualization/

Графики профилей, scatter-plots, общий стиль для рисунков ВКР.

- `style.py` — `MODEL_COLORS`, шрифт serif, `apply_thesis_style()` для активации стиля 300 dpi.
- `stress_profiles.py` — `plot_profile_single_component`, `plot_profile_all_components`, `plot_scatter_grid`.

Цветовая палитра моделей фиксирована — она используется во всех рисунках для согласованности.
