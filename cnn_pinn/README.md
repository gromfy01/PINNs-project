# CNN+PINN: поля остаточных напряжений по режиму волочения

Пробный прогон по ТЗ «CNN+PINN» на существующих данных (2443 отчёта Abaqus прежней работы).
Структура повторяет п. 9 ТЗ. Данные и прогоны в git не входят (`data/`, `runs/`).

## Состав

| Файл | Что делает |
|---|---|
| `src/prepare.py` | сырые `.rpt` → режимы, отбраковка, установившаяся зона, сетка r–z (п. 3) |
| `src/physics.py` | разностные операторы, hard-потенциалы N, M (прил. А), невязки и ГУ |
| `src/models.py` | архитектура A: сверточный декодер с FiLM и CoordConv, варианты `hard` и `data`; одномерная базовая модель `profile1d` (прил. А.8) |
| `src/train.py` | обучение по конфигу, разбиение режимов, ранняя остановка, сохранение весов и метрик |
| `src/evaluate.py` | метрики п. 7 и те же величины для данных МКЭ и для модели «среднее поле» |
| `src/plots.py` | карты полей и радиальные профили (п. 8) |
| `tests/test_physics.py` | модульные тесты физики и разбиения |

## Запуск

```bash
python src/prepare.py --raw <Raw_Data> --out data/trial_w2.npz      # ~1 мин на 4 ядрах
python tests/test_physics.py
python src/train.py --config configs/hard.yaml --seed 0
python src/train.py --config configs/data_only.yaml --seed 0
python src/train.py --config configs/profile1d.yaml --seed 0
python src/plots.py --data data/trial_w2.npz --runs runs/hard_s0 runs/data_only_s0 --out runs/figs
```

## Настройки пробного прогона (по умолчанию, до ответов на вопросы по ТЗ)

* Режимы: Q_d ≤ 0.2. Исключены незавершённые расчёты, опечатка μ, группы с побитово одинаковым
  полем при разных μ (целиком), утонение после волоки больше 0.5 мм и режимы, у которых
  установившаяся зона короче окна. Утонение больше 0.1 мм и осевая сила больше 10 МПа помечаются.
* Область: окно 2R в центре установившейся зоны, R — измеренный радиус поверхности,
  сетка 32 × 64 (шаг по ρ и по ζ одинаковый, ≈ 0.032).
* Признаки: Q по площади (из обжатия по диаметру), l_к/R_вых при поясе k·D₀, α в радианах, μ,
  log v, log Δ. Стандартизация по обучающей выборке.
* Разбиение 70/15/15 по режимам, стратификация по (Q_d, α), семейства, отличающиеся только μ,
  целиком в одной выборке.
* Масштаб напряжений — 300 МПа для всех компонент. AdamW, lr 2·10⁻³, OneCycle, до 200 эпох,
  ранняя остановка по macro-RMSE на валидации (терпение 30), CPU.
* Невязка в метриках считается разностным оператором 4-го порядка, а hard-поля строятся
  оператором 2-го порядка, поэтому критерий невязки не тавтологичен.

Подготовка данных использует парсер `publication/code/raw_probe.py` прежней работы.
