# Пробный прогон CNN+PINN на существующих данных (01.11.2026)

**Настройки** (по умолчанию из вопросов по ТЗ):
- 1466 режимов (Q_d ≤ 0.2);
- окно 2R в установившейся зоне, сетка 32 × 64;
- одно разбиение 1019 / 221 / 226 режимов, все прогоны на нём;
- три варианта по три сида, CPU, 4 потока.

**Исключено из 2443 расчётов:**

| причина | режимов |
|---|---|
| группы с одинаковым полем при разных μ | 410 |
| Q_d = 0.25 | 228 |
| незавершённые | 158 |
| установившаяся зона короче окна 2R | 156 |
| утонение больше 0.5 мм | 24 |
| опечатка в μ | 1 |

Режимы с осевой силой больше 10 МПа и с утонением 0.1–0.5 мм оставлены с пометкой: в тесте их 115 из 226.

**Файлы:**
- `summary.md`, `summary.csv` — метрики п. 7, среднее ± СКО по сидам, рядом — данные МКЭ и «среднее поле».
- `compare.md` — попарное сравнение вариантов на одних и тех же тестовых режимах.
- `data_report.md` — отчёт о данных.
- `fields_*.png`, `profiles_*.png` — карты полей и радиальные профили двух тестовых режимов (сид 0): с медианной ошибкой hard и с ошибкой на 90-м перцентиле.

## Выводы

1. **Точность.** macro-RMSE по четырём компонентам:

   | вариант | macro-RMSE, МПа | RMSE σ_z, МПа |
   |---|---|---|
   | hard | 6.15 ± 0.09 | 16.6 |
   | одномерная модель | 6.41 ± 0.06 | 17.0 |
   | «только данные» | 7.17 ± 0.16 | 19.8 |

   Hard точнее варианта без физики на 74 % тестовых режимов и одномерной модели — на 72 %. Доли посчитаны по ошибке, усреднённой по сидам. Медианы выигрыша 0.4 и 0.25 МПа. Разница значима и при подсчёте по 87 семействам, отличающимся только μ (p < 10⁻⁷). Разброс ± отражает только инициализацию, влияние разбиения не проверялось.

2. **Физика.**
   - **Граничные условия** hard выполняет точно.
   - **Осевая сила** у hard 0.1 МПа: разностные операторы дают ноль с точностью O(h²).
   - **Невязка уравнений**, RMS радиального / осевого, МПа:

     | | радиальное | осевое |
     |---|---|---|
     | hard | 0.6 | 0.2 |
     | данные МКЭ на той же сетке | 31.7 | 25.3 |
     | данные МКЭ во внутренних узлах | 19 | 13 |
     | вариант без физики | 19.9 | 7.8 |

3. **Ошибку определяет осевая сила в данных.**
   - 67 тестовых режимов с осевой силой больше 10 МПа дают 77–80 % суммарной квадратичной ошибки hard. Их macro-RMSE 9.1 МПа против 4.0 у остальных.
   - Около 3/4 квадратичной ошибки hard по σ_z — средняя по сечению σ_z в данных, которую hard по построению зануляет. Если сравнивать с данными, из которых она вычтена, RMSE σ_z у hard 8.1 МПа вместо 16.7.
   - Вариант без физики эту составляющую тоже не выучивает: 11.1 вместо 19.3. По параметрам режима она не предсказуема.
   - Утонение само по себе почти не влияет: macro-RMSE 4.1 против 3.9 у режимов без пометок. Разница 7.4 против 5.4 по флагу утонения возникает за счёт режимов, где есть и утонение, и осевая сила.
   - Наибольшая ошибка σ_z во внутренних узлах (126–140 МПа по сидам) у всех прогонов приходится на один и тот же режим: осевая сила 65 МПа, утонение 0.42 мм.

4. **Пользу 2D этот прогон не показывает.**
   - Одномерная модель уступает hard на 0.25 МПа (≈ 4 %), по σ_z на поверхности они равны.
   - Выигрыш hard почти целиком в радиальном профиле, усреднённом по z. В части, зависящей от z, hard не лучше: в окне 2R поле почти постоянно по z, и hard эту слабую изменчивость почти не воспроизводит.
   - Проверять 2D нужно на более длинном окне или ближе к волоке (вопрос Б1).

5. **τ_rz не предсказывает ни одна модель.** RMSE 1.2–1.5 МПа против 1.21 у «среднего поля» и 1.26 у нулевого τ_rz. По виду τ_rz в окне — шум интерполяции: такого же порядка он на оси и на поверхности, где должен быть нулём, корреляция по сетке всего на 2–3 узла.

6. **Критерии п. 11 в нынешней формулировке.**
   - **RMSE.** Пороги проходят все варианты. По σ_z запас около 2 раз у hard и одномерной модели и 1.7 раза у варианта без физики (порог 33.4 МПа). Пороги для σ_r и τ_rz (5 % размаха σ_z) проходит даже «среднее поле».
   - **σ_z на поверхности.** Допуск max(10 %, 15 МПа) (по среднему по окну) не выполняется у 18 % тестовых режимов у hard, у 19 % у одномерной модели и у 21 % у варианта без физики. Почти все провалы — режимы с осевой силой.
   - **Знак σ_z** на поверхности и на оси у hard и одномерной модели совпадает с МКЭ во всех режимах, где |σ_z МКЭ| > 15 МПа. У варианта без физики на поверхности 1–2 промаха в двух сидах из трёх.

7. **Время.** 2D-прогон около 21 мин на CPU (до 200 эпох), одномерный — 15 с. Предсказание 1.4–1.9 мс на режим у 2D-моделей (пакетами по 64), 0.1 мс у одномерной.
