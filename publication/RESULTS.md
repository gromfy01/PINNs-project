# Результаты прогонов

Сгенерировано `publication/experiments/make_results.py` из `results/runs.csv`. Данные — пересобранный из сырых `.rpt` датасет (`publication/code/dataset.py`), 1848 наборов; целевые поля — истинные `(σ_rr, σ_θθ, σ_zz, τ_rz)`, а не то, что лежало в прежнем `y_stress.pkl` (ERRATA E-18).

Протокол одинаков у всех семейств: AdamW, без планировщика, те же эпохи, батчи, ранняя остановка, сиды и архитектура; отличается только состав функции потерь. Гиперпараметры зафиксированы априори и на held-out регионах не подбирались.

Базовая линия самих данных FEM (то, с чем сравнивать физаудит): |σ_rr| на поверхности **3.56 МПа**, |τ_rz| **0.33 МПа**.

Прогонов в отчёте: **60**.

### 1.0б Нормированные метрики

Абсолютная macro-RMSE сравнима между сплитами только при равной дисперсии held-out региона, а она не равна. Поэтому рядом обязательны macro-NRMSE (RMSE, делённая на std компоненты) и R²: они отвечают на вопрос «лучше ли модель предсказания средним», а RMSE — нет.

macro-NRMSE / macro-R²

| сплит | MLP (data-driven) | PINN (сильная форма) | VPINN (слабая форма) |
|---|---|---|---|
| `random` | 0.267 / +0.888 | 0.273 / +0.881 | 0.259 / +0.896 |
| `extrap:alpha_max` | 0.826 / -0.454 | 0.855 / -0.600 | 0.789 / -0.346 |
| `interp:alpha_mid` | 0.519 / +0.551 | 0.540 / +0.510 | 0.509 / +0.592 |
| `matched:alpha_max` | 0.242 / +0.916 | 0.260 / +0.896 | 0.249 / +0.907 |

> **Ключевое сравнение.** Изъятие ВНУТРЕННЕГО уровня фактора (`interp:alpha_mid`) даёт macro-RMSE 23.0 МПа при R² = +0.55; выход ЗА диапазон (`extrap:alpha_max`) — 21.7 МПа при R² = -0.47. В абсолютной RMSE разница мала, а по R² она качественная: во внутреннем срезе модель ещё объясняет часть дисперсии, за диапазоном — хуже предсказания средним. Именно это различие случайный hold-out (R² ≈ 0.89) не показывает вовсе.
