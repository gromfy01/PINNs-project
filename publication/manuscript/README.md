## Как проверялись тексты

1. Черновик каждого раздела написан по источникам (`RESULTS.md`, `RESULTS_v1_vs_v2.md`,
   `VALIDATION.md`, `QA_DATA_AND_Z.md`, `ERRATA.md`, код).
2. Независимая сверка каждого числа с источником (19 расхождений исправлено, помечены
   `% FIXED:`); таблицы — без замечаний.
3. Сквозная критика четырёх блоков: согласованность чисел между разделами,
   дубли меток, ссылки на несуществующие разделы, пояснения из подписей —
   в текст. Правки помечены `% EDIT:`.

## Что обязательно править ВНЕ §2.2–2.3 и §3.2

Указание «всё, кроме 3.2, без изменений» не выполнимо буквально — ниже места,
где старый текст противоречит новым результатам.

- **Аннотация (E-15).** «macro-mean squared error 11.51 MPa» → v2-числа
  (random: 7.98–8.04 МПа; экстраполяция 8.3–48 МПа); «single cluster of three
  models» и «three backends» → два бэкенда, неразличимые по точности
  (p = 0.27 и 0.17), PyTorch в 1.65 раза быстрее; преимущество PINN малое
  (0.3–1.9 МПа), значимо на 4 сплитах из 13 без поправки, ни на одном — с
  поправкой Холма; главный аргумент — физическая допустимость и устойчивость к
  порче меток (наклон −14.20 МПа/долю, p = 0.00036).
- **Conclusions (E-14, E-10/E-19).** Снять «backend matters» и дубль списка
  компонент; тезис о дефиците данных не заявлять.
- **Библиография (E-13).** `\bibliographystyle` раскомментировать,
  `\bibliography{cas-refs}` без расширения, пересобрать `.bbl`; все
  `\cite{TODO-…}` в новых разделах требуют рабочего `.bib`.
- **Старый §2.2.4** «Adam followed by LBFGS … cosine schedule» (E-05) — удалить:
  такого протокола в коде нет, реальный протокол описан в `sec23`.
- **Старые Figs 11–12 и уравнение ГУ при r = 1.5R (E-01)** — снять; заменяет
  `fig6_residual_maps.png`.
- **Константы Джонсона–Кука** (A = 500, B = 300, n = 0.4) и температура —
  убрать из §2: расчёт упруго-идеально-пластический, σ_y = 320 ± 10 МПа
  (измерено из полей, `VALIDATION.md` §2–3), термосвязки нет.
