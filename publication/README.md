# publication/ — работа над ошибками по отклонённой статье

Материалы пересабмита по `CIRPJ-D-26-00824` (CIRP J. Manuf. Sci. Technol.,
отклонена 2026-08-23). Каталог самодостаточен: код здесь не зависит от `.pkl`
и запускается без GPU.

| Файл | Что это |
|---|---|
| [`PLAYBOOK.md`](PLAYBOOK.md) | **основной документ** — постановка, данные, код, план работ, критерии приёмки |
| [`ERRATA.md`](ERRATA.md) | реестр всех найденных ошибок со статусом каждой |
| [`audit/RAW_AUDIT.md`](audit/RAW_AUDIT.md) | числа, полученные из сырых `.rpt`; источник истины для остальных документов |
| `code/` | пайплайн: фильтры, экстраполяционные сплиты, единый протокол, статистика, кривые обучения, порча меток, физпроверки |
| `tests/` | тесты инвариантов |

## Быстрый старт

```bash
python publication/tests/test_pipeline.py          # ничего не требует, кроме numpy/scipy
```

Воспроизвести аудит данных (нужен релиз `raw-data-v1`, 1.2 ГБ):

```bash
python publication/audit/run_raw_audit.py --root <распакованный Raw_Data> --out audit.npz
python publication/audit/make_report.py   --npz audit.npz
```

## Что здесь важно знать сразу

Три вещи, которые меняют интерпретацию результатов отклонённой версии и
подтверждены измерением, а не рассуждением:

1. окно «25–75 %» — **осевое**; радиальный профиль покрывает весь радиус,
   свободная поверхность при `r_norm = 1`, а не 1.5 (E-01);
2. редукция уравнений равновесия оправдана для радиального уравнения
   (отброшено 1.3 %) и **не** оправдана для осевого (68 %) — E-02;
3. 13.2 % наборов сырой сетки — один и тот же расчёт под несколькими метками
   трения (E-06).

Подробности и что с этим делать — в `PLAYBOOK.md`.
