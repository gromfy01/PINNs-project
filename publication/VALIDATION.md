# Верификация вместо валидации: что можно предъявить рецензенту

Рецензент указал на отсутствие экспериментальной валидации МКЭ (ERRATA E-09).
Эксперимента нет и в рамках этой работы не будет. Предложенный научным
руководителем путь — сверка с аналитическими решениями Зибеля и Авитцура —
проверен и оказался **частично выполнимым**, причём выполнимая часть
обнаружилась там, где её никто не искал.

---

## 1. Главная находка: напряжение волочения извлекается из «бракованных» расчётов

**158 из 2443 расчётов (6.5 %) сняты в момент, когда проволока ЕЩЁ В ВОЛОКЕ.**
Это ровно те наборы, которые я снял из обучающей выборки как незавершённые
(E-24). Для обучения они непригодны, но именно они — и только они — несут
информацию, которой нет больше нигде: пока проволока захвачена волокой,
протянутая часть находится под тянущей нагрузкой.

Проверено прямым интегрированием `σ_d = (1/πR_f²)·∫σ_zz·2πr dr` по сечениям
вдоль оси, набор `1020_2a_32_rd_2000_cal_10_v_10_fric_0100`:

| z, мм | R, мм | F/A, МПа | |
|---|---|---|---|
| 4.7 | 13.97 | **237.0** | протянутая часть |
| 14.1 | 13.99 | **233.7** | |
| 32.8 | 14.00 | **232.9** | |
| 60.9 | 14.06 | **231.7** | |
| 70.3 | 15.39 | 175.9 | конус |
| 79.6 | 17.90 | 37.1 | |
| 89.0 | 18.00 | −0.5 | заготовка |
| 135.9 | 18.00 | 0.1 | |

По протянутой части F/A постоянно с точностью 1.4 %, через конус спадает, в
недеформированной заготовке равно нулю. Это и есть напряжение волочения.

Для сравнения, на 1756 наборах рабочего датасета сечение **разгружено**:
`|∫σ_zz dA|/A` = 5.3 МПа (медиана) при `rms(σ_zz)` = 167 МПа, тогда как Зибель
для тех же режимов требует 28…362 МПа. На данных статьи напряжение волочения
не извлекается в принципе — и это надо сказать прямо.

После фильтрации (σ_d > 20 МПа, разброс вдоль прутка < 8 %, Мизес в конусе
> 250 МПа) остаётся **76 расчётов**, σ_d = 155…283 МПа, медиана 210.

## 2. Материальная карта восстанавливается из поля

В конусе материал активно течёт, поэтому `S.Mises` там равен напряжению
течения. Конус выделен по осевой координате как зона, где радиус поверхности
меняется (122 файла, 115 239 узлов).

Верхняя огибающая Мизеса — резкий потолок:

| перцентиль | МПа |
|---|---|
| p95 | 324.2 |
| p99 | 333.5 |
| p99.9 | 336.6 |

По текущим узлам (Мизес ≥ p85): **σ_y = 317.4 − 5.1·ε МПа**, медиана 316.3,
СКО 15.2. Наклон в пределах шума.

**Вывод: материальная карта расчёта — упруго-идеально-пластическая,
σ_y = 320 ± 10 МПа, упрочнение неотличимо от нуля.**

### Следствие, которое надо исправить до подачи

Константы Джонсона-Кука из `physics/constitutive.py` и
`docs/physics_equations.md` (A = 500, B = 300, n = 0.4, C = 0.05, m = 1)
**противоречат данным вдвое**:

| ε_eq | по этим константам | измерено в расчёте |
|---|---|---|
| 0.05 | 591 МПа | ~316 |
| 0.20 | 658 МПа | ~316 |
| 0.50 | 727 МПа | ~316 |

В репозитории они помечены как пример из ВКР, но если фигурируют в рукописи
как описание расчёта — это самостоятельная ошибка, которую рецензент найдёт
быстрее, чем отсутствие эксперимента. **Убрать или заменить на фактическую
карту.**

## 3. Ответ на вопрос о температуре

Температура **не является препятствием**, но не потому, что мала: её в расчёте
**нет вообще**, вместе со всей моделью Джонсона-Кука. Три независимых
измерения:

1. **Полей нет.** Сплошной поиск по 2443 файлам: `NT11`, `TEMP`, `PEEQ`, `HFL`,
   `SDV`, `U`, `RF`, `CPRESS`, `CSHEAR` — ноль вхождений.
2. **Нет ни упрочнения, ни скоростного члена** — двух из трёх сомножителей ДК.
   Кривая течения плоская (§2). Парные сдвиги по строго совпадающим (Q, α, μ, k)
   при изменении скорости: +2.0 % (5→10), 0.0 % (10→20, n = 417), −2.7 %
   (20→40, n = 552) — немонотонно и в пределах ±6 %, тогда как C = 0.05
   требовал бы монотонных +19.6 % от v = 5 к v = 250.
3. **Объёмная деформация чисто упругая.** Совместная подгонка
   `tr(LE) = σ_kk/(3K) + 3α_th·ΔT` для партии v = 250 даёт K = 151.0 ГПа
   (что при E = 210 ГПа отвечает ν = 0.268 — табличное значение для стали) и
   эквивалентную ΔT = 0.0 К на всех уровнях обжатия. Теплового расширения нет.

**Оценка «а если бы была».** С измеренным σ_y = 320 МПа, β = 0.9,
ρc = 3.815·10⁶ Дж/(м³·К): ΔT = 6.6 / 26.4 / 85.4 К (min / медиана / max),
вклад трения отдельно до 48 К. Термическое разупрочнение по ДК: медиана
1.76 %, максимум 5.69 %. Сравнивать надо с разрешением данных: один шаг по μ
сдвигает σ_zz на поверхности на 15.3 МПа (10 % уровня), один шаг по α — на
34.6 МПа (23 %). **Медианная температурная поправка вдвое меньше эффекта
одного шага по трению.**

### Формулировка для статьи

Не «температурной поправкой пренебрегаем» — это приглашает спросить, откуда
взяты T₀, T_m и m. А так:

> В расчёте использована упруго-идеально-пластическая модель с σ_y = 320 МПа
> (значение восстановлено из поля эквивалентных напряжений в очаге деформации);
> термомеханическая связка не включалась. Оценка адиабатического разогрева по
> балансу работ даёт ΔT = 7…85 К (медиана 26 К), чему при типичных константах
> термического разупрочнения отвечает снижение сопротивления деформации на
> 0.7…5.7 %, что лежит ниже разрешающей способности выборки по факторам плана.

Каждое число здесь измерено.

## 4. Аналитическая сверка: что получилось

Реализованы Зибель (три варианта записи, расхождение между ними 0.02…3.75 %)
и верхнеграничное решение Авитцура, выведенное заново. Замкнутая форма `f(α)`
сверена с прямым численным интегрированием до 8 знаков; предел α → 0, m = 0
даёт ровно `ln(1/(1−r))`.

Сравнение на шести независимых ячейках (Q, α), **ноль подгоняемых параметров**:

| МКЭ | Зибель | Авитцур |
|---|---|---|
| 155.2 | 138.8 | 143.8 |
| 192.1 | 181.7 | 184.2 |
| 197.7 | 221.1 | 214.2 |
| 236.1 | 227.3 | 226.9 |
| 240.6 | 272.1 | 261.2 |
| 237.7 | 259.7 | 263.2 |

Зибель MAPE **8.8 %**, Авитцур **5.7 %**.

**Некруговая сверка — самый сильный ход.** Значение σ_f, при котором Зибель
наилучшим образом описывает извлечённое σ_d, равно **318 МПа**, для Авитцура
**327 МПа**, против измеренных независимо в конусе **316–320 МПа**. Два
независимых определения одной величины совпадают в пределах 3 %. Структурно
это то же, что делает эксперимент: связывает интегральную характеристику
процесса с локальным свойством материала.

Парный тест трения: `dσ_d/dμ` = +754 МПа/ед (МКЭ) против +866 (Зибель), знак
верный в 96 % из 23 пар.

## 5. Оговорки, которые надо написать самим

Не дожидаясь рецензента:

1. **Проверка выполнена не на данных статьи.** Пересечение 76 пригодных
   расчётов с датасетом из 1756 наборов **равно нулю** — препроцессинг снял их
   как незавершённые. Формулировка обязана быть «на подмножестве расчётов той
   же модели, где кадр захвачен внутри волоки».
2. **Эффективное число точек мало.** Уникальных значений σ_d — 21, независимых
   ячеек (Q, α) — шесть, причём две содержат 3 и 1 расчёт.
3. **Контрольный тест провален при подгонке масштаба.** Заведомо бессмысленная
   модель `c·√ε` (без μ и α) даёт R² = 0.848 против 0.742 у Зибеля. Вся
   объяснённая дисперсия сидит в монотонности по обжатию. Заявлять можно
   **абсолютный уровень без подгонки** и **производную по μ**, но не общую
   объяснённую дисперсию.
4. **Влияние полуугла не проверяется:** в подвыборке есть только α = 12° и 16°.
5. **Трение через контактные величины не проверяется:** `CPRESS`/`CSHEAR`
   отсутствуют, волока выведена одним узлом, длина калибрующего пояска не
   восстановима.
6. **Аналитика не закрывает E-09.** И МКЭ, и Зибель, и Авитцур исходят из одной
   идеализации — идеально-пластического материала с постоянным σ_f, и в данном
   МКЭ это **измерено**. Их согласие проверяет сетку, контакт, решатель и
   баланс работ при заданной карте, но не соответствие карты реальной AISI 1020,
   которая на этих деформациях упрочняется примерно с 210 до 500–600 МПа.

## 6. Провенанс: скорость неотделима от партии расчётов

2443 расчёта собраны из семи партий `.odb` на четырёх дисках в трёх
соглашениях об именах, кампании 2022 → 2026, и **скорость совпадает с партией
один-в-один**: v = 5 → `E:/AISI_1020/Vel_5_updated`, v = 10 →
`V:/Wire_drawing/2026/odb`, v = 20 → `E:/Abaqus_calc/Vel_20`, v = 40 → две
партии на `E:/`, v = 250 → `H:/Calculations_Abaqus_2022`.

Численно: v 10→250 (разные диски) даёт +25.6 МПа на поверхности, а v 20→40
внутри одного семейства — только −2.7 МПа. Подгонка объёмной деформации даёт
K = 151.0 ГПа в партии v = 250 и нефизичные 85.6–122.4 ГПа в остальных.

**Признак «скорость» в суррогатной модели частично кодирует идентичность
партии, а не скорость.** Выводы по скорости надо ограничить и сказать об этом
самим — это добавляет доверия, а не убавляет.

## 7. Что предъявить вместо валидации

Раздел «верификация решения», пять внутренних тестов на 1756 наборах:

| тест | результат |
|---|---|
| самоуравновешенность сечения | \|∫σ_zz·2πr dr\|/A = 5.3 МПа против rms 167 → **3.2 %** |
| локальное равновесие | невязка **2.1 %** суммы модулей членов |
| свободная поверхность | \|σ_rr\| = 4.0 МПа против 54.0 в объёме → **7.4 %** |
| ось симметрии | \|σ_rr − σ_θθ\| = 1.07 МПа → **0.6 %** |
| условие текучести | max Мизеса 232.6 при σ_y = 320 → **не нарушено нигде** |

Плюс кинематическая состоятельность: `R_вых/(R₀(1−Q))` = 1.0011 (0.11 %),
`|tr(LE)|` = 5.1·10⁻⁴ (несжимаемость 0.05 %). Заодно это независимо
подтверждает E-22: площадная трактовка Q промахивается на 5 %.

### Что сказать рецензенту прямым текстом

> Мы признаём отсутствие экспериментальной валидации и не заявляем её. Область
> применимости сужена соответственно: предлагаемая суррогатная модель
> воспроизводит поле напряжений конкретной МКЭ-постановки, а не поведение
> реальной проволоки; её назначение — замена дорогого расчёта, а не
> эксперимента. Для обоснования того, что воспроизводимый объект вычислен
> корректно, добавлен раздел верификации (пять внутренних тестов, невязки
> 0.6–3.2 %) и раздел аналитической проверки баланса работ (Зибель, Авитцур,
> MAPE 8.8 % и 5.7 % при нуле подгоняемых параметров) на подмножестве расчётов,
> где доступно усилие волочения. Экспериментальная валидация вынесена в задачи
> дальнейшей работы с указанием конкретного метода — рентгеновской тензометрии
> на поверхности и послойного удаления для эпюры по сечению.

## 8. Действие с наивысшей отдачей

**Выяснить, живы ли `.odb` по путям из шапок отчётов.** Повторная выгрузка
`PEEQ`, `RF` (реакция на опорной точке волоки), `CPRESS`/`CSHEAR` хотя бы для
20–30 представительных режимов **из самого датасета** переводит в разряд
выполнимого: прямое сравнение усилия волочения на данных статьи,
количественную проверку фактора избыточной работы и проверку члена трения по
контактным напряжениям.

Это единственный шаг, меняющий картину качественно. Всё остальное — работа в
границах того, что уже потеряно при экспорте.
