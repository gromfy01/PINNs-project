# Сообщение Дмитрию: результаты пробного прогона CNN+PINN (01.11.2026)

Приложения: cnn_pinn/reports/2026-11-01_trial/ (README.md с выводами, summary.md, compare.md, data_report.md, графики fields_*.png и profiles_*.png).

Дмитрий, добрый вечер! пробный прогон на старых данных закончил, результаты и графики прикладываю. коротко:

данные: из 2443 расчётов в набор вошли 1466 режимов. исключены Q_d = 0.25, незавершённые, группы с одинаковым полем при разных μ, утонение > 0.5 мм и 156 режимов, где установившаяся зона короче окна 2R. режимы с осевой силой и умеренным утонением оставил с пометкой, в тесте их половина. сетка 32×64, одно разбиение 1019/221/226 режимов
сравнивал 3 варианта по 3 сида: hard (сеть выдаёт N и M), только данные (4 канала без физики) и одномерную модель (профиль по ρ с теми же ограничениями)
точность (macro-RMSE по 4 компонентам): hard 6.2 МПа, одномерная 6.4, только данные 7.2. по σ_z: 16.6 / 17.0 / 19.8 МПа. hard точнее варианта без физики на 74 % тестовых режимов (медиана выигрыша 0.4 МПа)
физика: hard выполняет ГУ точно, осевую силу держит около нуля (0.1 МПа), невязка радиального уравнения 0.6 МПа. у самих данных МКЭ на той же сетке 32 МПа (во внутренних узлах 19), у варианта без физики 20
основная ошибка - в режимах с осевой силой > 10 МПа: на них приходится почти 80 % квадратичной ошибки hard. около 3/4 ошибки по σ_z это как раз средняя по сечению σ_z в данных, которую hard по построению зануляет. если сравнивать с данными, из которых она вычтена, RMSE σ_z у hard 8.1 МПа вместо 16.7. вариант без физики её тоже не выучивает, то есть по параметрам режима она не предсказуема. утонение само по себе почти не влияет
одномерная модель уступает hard всего 0.25 МПа, и этот выигрыш в радиальном профиле, а не в зависимости от z: в окне 2R поле почти постоянно по z. так что пользу 2D этот прогон не показывает, её надо смотреть на более длинном окне (вопрос Б1). τ_rz не предсказывает ни одна модель: ошибка 1.2-1.5 МПа, не лучше среднего поля, по виду это шум интерполяции
пороги п.11 по RMSE все варианты проходят с запасом (σ_z 16.6 при пороге 33), а пороги для σ_r и τ_rz проходит даже среднее поле. зато допуск по σ_z на поверхности max(10 %, 15 МПа) не выполняется у 18 % тестовых режимов, в основном с осевой силой
считал на CPU: 2D-прогон около 21 мин, предсказание ~2 мс на режим

вывод: связка работает, hard лучше варианта без физики, но сейчас точность упирается в осевую силу в данных. дальше могу проверить вариант с вычтенной средней σ_z, soft и окно 3R, многое зависит от ответов по вопросам Б1-Б3. Если удобно, обсудим на созвоне
