# Ответ Дмитрию 19.10.2026: Zenodo после отказа EwC

Контекст: 19.10 EwC отклонил рукопись как выходящую за тематику журнала. Дмитрий выбирает между IJMMD и IJAMT.

Дмитрий, жаль, что EwC не взяли. Про Zenodo: я выложил всё двумя записями.

1. Код: https://doi.org/10.5281/zenodo.23352452 (версия 1.0.0, это архив релиза репозитория https://github.com/gromfy01/wire-drawing-pinn-surrogates). Там сборка обоих наборов из сырых отчётов, обучение всех трёх семейств, журнал всех 341 прогона, генераторы таблиц и рисунков и скрипты верификации по 112 расчётам. В README пошагово расписано, как воспроизвести результаты статьи.
2. Данные МКЭ: https://doi.org/10.5281/zenodo.23352871. Внутри два архива: Raw_Data.zip (2443 сырых отчёта Abaqus, 1.2 ГБ) и history_reports_112.zip (112 отчётов для верификации напряжения волочения).

DOI постоянные. Записи на Zenodo удалить нельзя, можно только выпускать новые версии.

В версию для Springer я уже вписал оба DOI в Declarations (Data availability и Code availability), так что для следующего журнала формулировка «on reasonable request» больше не нужна. IJAMT и IJMMD — оба журнала Springer с тем же шаблоном, так что пакет пересоберу быстро, останется переадресовать сопроводительное письмо.

И раз статья вернулась, перед новой подачей стоит внести правки из списка вычитки. Пришлите, пожалуйста, тот .tex, который вы отправляли в EwC, чтобы я вносил правки в вашу версию.
