## 1. Главные компоненты в датасете — обозначение или формирование?

**Это дефект формирования датасета, а не особенность обозначения.**

В `y_stress.pkl` физически лежат четыре величины:

| плоскость `.pkl` | что там на самом деле | mean\|Δ\| до кандидата, МПа | corr |
|---|---|---|---|
| 0 | `S.Max. Prin` (σ₁) | 0.019 | 1.0000 |
| 1 | `S.Mid. Prin` (σ₂) | 0.014 | 1.0000 |
| 2 | `S.Min. Prin` (σ₃) | 0.016 | 1.0000 |
| 3 | `S.S11` = σ_rr | 0.008 | 1.0000 |

Ближайший конкурент у каждой плоскости отстаёт на 21–107 МПа, то есть
отождествление однозначное. Компоненты `τ_rz`, `σ_θθ`, `σ_zz` в массиве
отсутствуют как самостоятельные величины: для `τ_rz` во всех четырёх плоскостях
`|corr| ≤ 0.14` и 0.00 % побитовых совпадений.

Вывод подтверждён четырьмя независимыми проверками, включая одну, поставленную
на опровержение. Решающая: на 11 944 бинах, где `S.Max.Prin` действительно
расходится с `S.S33` (средний разрыв 72.3 МПа), плоскость 0 совпадает с
`S.Max.Prin` с ошибкой **0.044 МПа** против 72.3 МПа для `S.S33`. Совпадение
не объясняется малостью сдвига.

Дополнительный аргумент: коммитнутый препроцессинг репозитория воспроизводит
`y_strain.pkl` на 91.8–95.0 % побитово, а `y_stress.pkl` — на 0.00 / 12.2 / 1.1 /
0.00 %. То есть опубликованный путь для напряжений физически не мог породить
этот массив; подмена произошла на шаге упаковки в `.pkl`.

Первичные числа: `publication/ERRATA.md`, запись **E-18**.

### Побочное следствие, важное для интерпретации прежних результатов

С учётом `PLANE_ORDER = [2, 0, 1, 3]` выходные слоты прежних моделей содержали:

| слот | метка в коде | что там на самом деле |
|---|---|---|
| 0 | `sigma_rr` | σ₃ |
| 1 | `sigma_tt` | σ₁ |
| 2 | `sigma_zz` | σ₂ |
| 3 | `tau_rz` | σ_rr |

Поэтому физический лосс прежней версии считал `∂σ₃/∂r + (σ₃ − σ₁)/r` — это не
уравнение равновесия. Граничное условие при этом проходило проверку **случайно**:
на свободной поверхности traction-free даёт σ_rr = τ_rz = 0, три главных
напряжения там суть `{0, σ_zz, σ_θθ}`, обе последние растягивающие, поэтому
σ₃ = 0 = σ_rr — обе занулявшиеся величины на поверхности действительно нулевые.
Именно это и позволило дефекту дожить до подачи.

## 4. Как учитывалась координата z при обучении?

Двумя способами — намеренно, потому что вопрос оказался нетривиальным, и это
прямо тот пункт, на который указал Reviewer #1.

### Основной трек: z не во входе, но окно по z задано явно

Вход `[Q, k, α, μ, v, r]`, один радиальный профиль на набор. Узлы берутся из
осевого окна 25–75 % длины (медиана длины окна 57.5 мм при радиусе 16.2 мм,
то есть L/R ≈ 3.5) и сворачиваются вдоль z медианой в 20 радиальных бинов.

Правомерность такой свёртки измерена, а не постулирована. Внутри окна вдоль z
приходится следующая доля полного разброса компоненты:

| компонента | доля разброса вдоль z | mean\|.\| до свёртки | после свёртки | падает в |
|---|---|---|---|---|
| σ_rr | 0.114 | 47.9 | 46.6 | 1.03 |
| σ_θθ | 0.116 | 56.6 | 54.4 | 1.04 |
| σ_zz | 0.098 | 140.2 | 137.6 | 1.02 |
| **τ_rz** | **0.397** | **3.22** | **0.68** | **4.71** |

Для нормальных компонент свёртка теряет 2–4 % — окно выбрано в установившейся
зоне, поле там почти однородно вдоль оси. Для касательной теряется **79 %**:
τ_rz внутри окна знакопеременный вдоль z и при осреднении взаимно уничтожается.
Это и есть причина, по которой τ_rz в одномерной постановке принципиально не
предсказуем — не свойство модели, а свойство представления данных.

Уравнения равновесия в этом треке записываются в редуцированной форме:

```
∂σ_rr/∂r + (σ_rr − σ_θθ)/r ≈ 0        отброшено ∂τ_rz/∂z
∂τ_rz/∂r + τ_rz/r          ≈ 0        отброшено ∂σ_zz/∂z
```

Отброшенное измерено на сетке 20 × 20 по 2443 наборам: для радиального
уравнения отброшенный член составляет **1.3 %** от суммы удержанных — редукция
законна. Для осевого — **68 %**, редукция незаконна. Более того, второе
выражение тождественно равно `(1/r)·∂(r·τ_rz)/∂r`, и его зануление означает
`τ_rz ≡ 0` на всём радиусе, а не баланс сдвига. Поэтому в основном треке
осевое уравнение как уравнение равновесия не используется; в коде оно
называется `zero_shear_residual` и снабжено явным статусом.

### Расширенный трек: z во входе, полная форма обоих уравнений

Вход `[Q, k, α, μ, v, z, r]`, поле берётся на сетке 8 × 20 по (z, r) без
осреднения вдоль z; z нормируется на границы окна (0 — вход, 1 — выход), r —
на радиус поверхности в том же сечении. Оба уравнения записываются полностью:

```
∂σ_rr/∂r + ∂τ_rz/∂z + (σ_rr − σ_θθ)/r = 0
∂τ_rz/∂r + ∂σ_zz/∂z + τ_rz/r          = 0
```

Обезразмеривание осевых членов ведётся по длине окна `L_char`, радиальных — по
`R_char`; отношение L/R ≈ 3.5, и подстановка сюда `R_char` была отдельно
найденной и исправленной ошибкой.

Результат абляции, 3 сида на конфигурацию, среднее ± ст. отклонение:

| сплит | модель | macro RMSE, МПа | осевая невязка `eq_z_full` |
|---|---|---|---|
| random | MLP (z во входе, без физики) | 18.42 ± 0.21 | 591 ± 22 |
| random | PINN, полная форма | 18.45 ± 0.06 | **404 ± 27** (−32 %) |
| random | PINN, редуцированная форма | 18.65 ± 0.27 | 620 ± 55 |
| экстраполяция по α | MLP | 28.92 ± 2.94 | 1609 ± 245 |
| экстраполяция по α | PINN, полная форма | 31.99 ± 2.56 | **1015 ± 194** (−37 %) |
| экстраполяция по α | PINN, редуцированная форма | 32.67 ± 3.81 | 1393 ± 424 |

Читается так: введение z и полной формы снижает осевую невязку на 32–37 %.
На случайном сплите это достигается без потери точности (18.45 против 18.42,
разница внутри разброса). На экстраполяционном сплите точность формально хуже
на 3.1 МПа при разбросе 2.5–2.9 МПа, то есть отличие в пределах одного
стандартного отклонения и как установленное подаваться не должно.

Отдельно отмечу: редуцированная форма осевую невязку не снижает вовсе
(620 против 591 у MLP на random), что согласуется с оценкой 68 % отброшенного.
