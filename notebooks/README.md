# notebooks/

| Notebook                         | Что внутри                                                     | Нужны данные? |
|----------------------------------|----------------------------------------------------------------|---------------|
| `00_quickstart.ipynb`            | Загрузить бандл, прогноз для одного набора, график 4 компонент | Нет           |
| `01_data_exploration.ipynb`      | Обзор FEM-датасета: распределения параметров, выбросы           | Да            |
| `02_stress_training.ipynb`       | Обучение моделей напряжений с нуля                             | Да            |
| `03_strain_pinn_vs_mlp.ipynb`    | Сравнение MLP и PINN на деформациях                            | Да            |
| `04_physics_audit.ipynb`         | Проверка ГУ и уравнений равновесия на прогнозах holdout         | Да            |

Notebooks с данными требуют `data/processed/X_*.pkl`, `y_*.pkl` (см. `data/README.md`).

Quickstart работает из коробки — нужны только бандлы из `results/bundles/stress/`, которые лежат в репозитории.
