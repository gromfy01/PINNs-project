# PINNs-project
Этот репозиторий содержит суррогатные модели на основе физически информированных нейронных сетей (PINN) для прогнозирования остаточных напряжений и накопленных деформаций в проволоке после процесса волочения

Проект включает пайплайн обработки данных Abaqus FEM, обучение шести архитектур (MLP с грид-поиском, MLP с Optuna, PINN на PyTorch, PINN на DeepXDE, PINN на JAX/Flax и VPINN со слабой формой уравнений равновесия), подбор гиперпараметров, оценку моделей по регрессионным метрикам и аудит физической согласованности через невязки уравнений равновесия и граничных условий.
