# PINNs-project — Суррогатные модели для прогноза остаточных напряжений и накопленных деформаций после волочения проволоки

Репозиторий содержит исследовательский проект по сравнению архитектур физически-информированных нейронных сетей (PINN), многослойных перцептронов (MLP) и вариационных PINN (VPINN) в задаче построения быстрых суррогатных моделей для прогноза распределений компонент тензоров остаточных напряжений и накопленных пластических деформаций по сечению проволоки после процесса осесимметричного волочения. Целевые поля получены из конечно-элементного моделирования в Abaqus и используются для обучения и тестирования моделей.

Работа выполнена в рамках выпускной квалификационной работы на факультете компьютерных наук НИУ ВШЭ.

## Инструкция по установке

### 1. Установка зависимостей

Требуется Python 3.10 или выше. Рекомендуется использовать виртуальное окружение.

```
python -m venv venv
source venv/bin/activate   # или .\venv\Scripts\activate в Windows

pip install -r requirements.txt
```

При работе с DeepXDE-моделями переменная окружения `DDE_BACKEND` должна быть установлена в `pytorch` **до** импорта `deepxde`. Это уже сделано в соответствующих модулях `models/stress_pinn.py`, но при ручном запуске в Jupyter необходимо учитывать порядок импортов:

```python
import os
os.environ["DDE_BACKEND"] = "pytorch"
import deepxde as dde
```

### 2. Загрузка данных

Данные конечно-элементного моделирования не включены в репозиторий из-за размера. Архив с обработанными `.npy` массивами доступен по ссылке:

**[Google Drive — данные ФЭМ](https://drive.google.com/your-link-here)**

После загрузки архив необходимо распаковать в директорию `data/processed/` так, чтобы получилась следующая структура:

```
data/processed/
├── stress_data.npy       # (4, N_sets, 20) — компоненты тензора напряжений
├── strain_data.npy       # (N_components, N_sets, 20) — пластические деформации
├── process_params.npy    # (N_sets, 5) — параметры процесса (Q, k, α, μ, v)
└── radii_norm.npy        # (N_sets, 20) — нормированные радиальные координаты
```

Подробное описание формата массивов и значений индексов компонент находится в файле `data/README.md`.

### 3. Загрузка обученных моделей

Веса всех шести обученных моделей (PINN-DeepXDE, PINN-JAX, PINN-PyTorch, MLP-grid, MLP-Optuna, VPINN) доступны в виде `.pkl` бандлов в разделе релизов репозитория:

**[GitHub Releases — обученные модели](https://github.com/gromfy01/PINNs-project/releases)**

Бандлы необходимо разместить в `results/bundles/`. Каждый `.pkl` содержит веса сети, нормировочные параметры (`mean_X`, `std_X`, `scaler_y_mean`, `scaler_y_std`) и одинаковые индексы holdout-выборки (`holdout_set_indices`), что позволяет сопоставлять прогнозы разных моделей на одном и том же тестовом множестве.

### 4. Настройка переменных окружения

Скопировать шаблон и заполнить значения по необходимости:

```
cp .env.example .env
```

Все переменные опциональны: при пустых значениях используются разумные значения по умолчанию (in-memory Optuna study, отключённый W&B, устройство `cuda` если доступно).

### 5. Быстрый старт

Минимальный пример загрузки модели и построения прогноза для одного набора параметров процесса находится в `notebooks/00_quickstart.ipynb`. Для запуска полного обучения с нуля:

```
python training/train_stress.py --config configs/stress_pinn.yaml
```

## Краткая сводка результатов

Сравнение проводилось на едином holdout-множестве из 305 наборов параметров (15% от 1730, seed=42). Лучшая модель по компонентному RMSE на napряжениях — PINN-DeepXDE (12.42 МПа). По τ_rz и SMAPE по большинству компонент лидирует MLP-grid. Полная таблица метрик и графики профилей по компонентам — в `results/tables/` и `results/figures/`.

Важный физический результат: на нормальных наборах нарушение граничного условия (σ_rr = 0 при r = r_max) у PINN-моделей в 4–6 раз меньше, чем у самих ФЭМ-данных, использованных для обучения. Это означает, что физически-информированные модели не наследуют шум исходных численных расчётов на границе и дают строгий физический prior, не зависящий от качества данных. Подробный аудит представлен в разделе ВКР `thesis/physics_subsection.tex` и воспроизводится скриптом `evaluation/physics_audit.py`.

## Замечания

- Проект использует данные конечно-элементного моделирования в Abaqus. Извлечение из `.odb` файлов выполнено отдельным скриптом на Abaqus Python API и в репозитории не воспроизводится — здесь работа ведётся уже с готовыми `.npy` массивами.
- Все физические потери в моделях вычисляются в нормированных координатах. Использование физических единиц (МПа, мм) приводит к коллапсу обучения из-за несоразмерности градиентов.
- Разбиение train/val/test выполнено group-aware: все 20 радиальных точек одного набора параметров остаются в одной части. Случайное построчное разбиение даёт утечку данных.
- При построении графиков сравнения с истиной обязательно применять перестановку компонент `PLANE_ORDER = [2, 0, 1, 3]` к **обоим** массивам — прогнозу модели и эталону. Несоблюдение даёт ложно отрицательный R² для нормальных компонент.
